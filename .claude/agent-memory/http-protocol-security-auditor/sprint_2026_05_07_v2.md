## Key facts for future sessions

- `mountAt()` RawPath bug: when prefix="/api" and RawPath="/api%2f...", TrimPrefix succeeds
  but result "%2f..." lacks leading "/" — violates url.URL contract. Fix: check trimmed[0]!='/'.
- HandleFast bypass: Group.Use() stdlib middleware never runs for HandleFast routes — by design
  but undocumented security trap. No panic, no warning, handler just runs unauthenticated.
- CL.TE "smuggling": Go stdlib uses TE (chunked) and ignores CL per RFC 9112. The second
  request in the body becomes a pipelined request. This is correct behaviour, not a vulnerability.
  Only dangerous when deployed behind a frontend that uses CL while backend uses TE.
- HTTP/2 CVEs (CVE-2023-44487, CVE-2024-27316): govulncheck clean on Go 1.26.2.

**Why:** Pre-release v1.2.0 security audit, parallel sprint with 7 other agents.
**How to apply:** When auditing Mount or redirect paths, check for RawPath contract violations.
  When advising on HandleFast usage, always warn about Use() bypass.
