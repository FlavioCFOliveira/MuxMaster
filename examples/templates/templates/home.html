MuxMaster Templates Example

A minimal multi-page website demonstrating server-side HTML rendering with Go's built-in html/template package and MuxMaster routing.

What this example shows

  • Layout inheritance — a base template defines the page chrome; page templates fill {{"{{"}}block "content" .{{"}}"}}.
  • Template data — a PageData struct carries per-request values to every template.
  • POST–Redirect–GET — form submission creates a guestbook entry and redirects back, preventing duplicate submissions on browser refresh.
  • Flash messages — a transient success banner appears on the first GET after a successful POST.
  • Form re-population — on validation failure, the form re-renders with submitted values and per-field error messages.
  • Static files — /static/* serves embedded CSS alongside dynamic routes.
  • Custom 404 — a themed HTML error page instead of Go's plain-text default.
  • Embedded assets — templates and CSS are compiled into the binary via embed.FS.
