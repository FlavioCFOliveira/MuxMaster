How layout inheritance works

base.html defines a template named "base" that contains the page chrome and two block directives:

  • block "title" — the <title> tag content
  • block "content" — the main body content

Each page template redefines these blocks with define. At startup, every page is pre-parsed into its own *template.Template together with base.html, so each template set contains exactly one definition per block. Rendering calls ExecuteTemplate(w, "base", data).

MuxMaster features used

  • r.GET / r.POST — page and form routes
  • r.ServeFiles — embedded static assets
  • r.NotFound — custom 404 handler
  • r.Pre(mw.CleanPath()) — URL normalisation before routing
  • mw.RequestID, mw.Logger, mw.RecovererWithLogger
