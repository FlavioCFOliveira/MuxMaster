## Harness validity defect (the distinct part of this finding)

The task reported that `TestTiming_ErrorOracle_404vs405` returned HTTP 401 for
all sampled iterations of both the "404" and the "405" requests, because
`buildErrorOracleMux()` registers `middleware.BasicAuth` with `r.Use(...)` and
the authentication gate therefore answers before the 404/405 path. The
harness comment at `error_oracle_test.go:89-93` asserts the opposite
("For 404/405, the mux returns these before reaching the handler, so
BasicAuth does NOT run").

Consequence: the 404-vs-405 number above does not measure the 404-vs-405
oracle. The LOW classification of that pair rests on invalid evidence. The
accepted route-existence oracle itself remains documented in `SECURITY.md`
from other measurements (MM-2026-0026 / TSC-2026-0005).
