### 5.2 Common harness rules (defensive against zero-day)

Every harness MUST:
- Use `t.Cleanup` and process-level rlimits (`syscall.Setrlimit RLIMIT_AS`, `RLIMIT_NOFILE`) to bound blast radius.
- Recover from panic in the test goroutine and convert to `t.Errorf`; never let a single repro abort the run.
- Time-bound each repro with `context.WithTimeout(t.Context(), 30*time.Second)` (or shorter).
- Run with `-race -count=1`; record `GOMAXPROCS` and `GOGC` env at start.
- Emit progress every 500 iterations to a JSON line file under `/reports/<agent>/evidence/2026-05-07-S8/<H8-NN>/progress.jsonl`.
