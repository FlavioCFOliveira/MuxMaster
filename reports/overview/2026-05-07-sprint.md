## 2. Threat-modeling deltas to investigate

### 2.1 Newly minted invariants under test

1. **HandleFast bypasses `Use` middleware** — by design, but: registering an auth middleware via `Use()` and a route via `HandleFast` silently *unauthenticates* it. Documentation-only mitigation. Verify failure modes (mixed Handle + HandleFast under same Group).
2. **`idxWild` tree (`Mount`)** — a `*`-method route exists *outside* the standard method dispatch and is checked *after* TSR/RFP redirects. Verify that auth middleware registered on a Mounted handler runs before the inner stdlib router.
3. **`muxConfig` frozen at first `ServeHTTP`** — Mutation of `m.PanicHandler`/`NotFound`/etc. after first request is a documented data race (MM-2026-0017) but `cfg` snapshot only captures the *bool* `hasPanicHandler`. Setting `PanicHandler` non-nil before first request and `nil` after is a documented race; check whether the inverse (nil → non-nil after first request) silently demotes to no-recovery.
4. **`setReqCtxUnsafe`** — reflection-derived offset of `http.Request.ctx` written via `unsafe.Add`. Re-audit under Go 1.26 layout, race detector, and verify no path can reuse a `reqBundle` after the handler returns (e.g. via stored `*http.Request` in a goroutine).
5. **OAuth2 cache eviction race** — `evictExpiredLocked` only runs on the *write* path when full; under sustained low-write/high-read with all entries expired, reads still return stale-`Active`-true entries until the next write. Validate `time.Now().After(expiry)` is checked on every read (it is; double-check no off-by-one with monotonic clock).
6. **JWT alg confusion with mixed key material** — if `Algorithms: ["HS256","RS256"]` and the operator supplies both `Secret` and `PublicKey`, can a token forged with `alg=HS256` and signed using the RSA *public* bytes as the HMAC key validate? RFC 8725 §3.1 attack. Construction-time validation maps each alg to its key but `verifyFn` re-dispatches on header `alg` — confirm no path accepts a sender-chosen alg from a different family with shared key material.

### 2.4 Top 10 zero-day-style hypotheses to chase

1. **JWT alg-confusion via shared key material when `Algorithms` mixes HS* and RS*/ES*.** Construction validates each alg has *its* key, but `verifyFn` dispatches on the *token's* `alg` header — confirm an attacker cannot supply `alg=HS256` to a server configured with both HS and RS keys.
2. **`setReqCtxUnsafe` ABI drift on Go 1.26.x point releases** — confirm `init()` panics-or-falls-back rather than silently writing into the wrong field if `ctx` is renamed/reordered.
3. **`idxWild` Mount tree bypasses `redirectFixedPath` canonicalisation** (H-J) — possible double-handler match where canonical path is owned by Mount but TSR/RFP redirects to a different handler.
4. **CORS silent-permissive when `AllowedOrigins` is empty and `Origin` is set** — `len(opts.AllowedOrigins)==0` falls through to `next.ServeHTTP(w,r)` with no CORS headers but also no rejection. Confirm whether this is intended.
5. **OAuth2 cache key collision** — sha256(token) is 32 B; collision-resistant, but cache map uses `[32]byte` directly; confirm Go's map hash on `[32]byte` doesn't expose a HashDoS via attacker-chosen tokens (it shouldn't — sha256 is secure).
6. **`apiKey` map iteration order leak at construction** — pre-hash loop is O(n) at construction (no leak); but if `Keys` is mutated post-construction, the hashed map is stale. Confirm doc says map is read-only after construction.
7. **`request_id` propagation to `recoverer` log line** — recoverer logs `r.URL.Path` but not request_id; this is a debuggability gap, not a security gap, but verify panic log doesn't leak the full URL with embedded secrets in path params (e.g. `/users/:token/...`).
8. **`compress` BREACH oracle on `oauth2` cached scope echo** (H-D) — confirm SECURITY.md MM-2026-0030 mention is sufficient or whether oauth2 introspection responses warrant explicit "do not echo Scope" guidance.
9. **`Mount` `RawPath` trim asymmetry** — `mountAt`'s `strings.TrimPrefix(r.URL.RawPath, prefix)` zeroes RawPath if no match, but if `RawPath` is *encoded* (`%2f` instead of `/`) then `TrimPrefix` won't strip a literal `/foo` prefix — RawPath is zeroed and the inner handler sees only the decoded Path. Test for asymmetric routing decisions.
10. **`HandleFast` + `Group.Use` skip** — Group's stdlib middleware silently does NOT wrap fast routes registered via `g.HandleFast`. Operators who register `g.Use(auth)` then `g.HandleFast(...)` get an unauthenticated route. The bypass is structural and trivial to mis-use.
