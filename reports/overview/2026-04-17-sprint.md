1. **Evidência de zero findings Critical/High no commit de tag v1.0.0** — ou findings com fix mergeado e verified antes do tag

3. **Superfície de ataque documentada** — attack trees para todos 5 top goals completas
4. **Baseline de fuzz/property tests** — pelo menos 10h cumulativas de fuzz nos 4 alvos principais, corpus persistido
5. **Invariant catalogue** — mínimo 8 invariants testados por property tests (I-01 a I-08)
6. **Transposition table actualizada** — scan dos últimos 90 dias de GHSA/NVD para Go + routers
7. **Hypotheses resolvidas** — todas as 30 hipóteses iniciais `open` em `hypotheses.md` têm verdict `confirmed`/`refuted`/`partial`
8. **Release recommendation defensible** — posture.md publicado com Ship/Hold/Conditional + fundamento

## 7. Escalation paths (obrigatórios)

### Intra-sprint escalation
| Evento | Acção imediata |
|---|---|
| Qualquer Critical finding | Threat-modeler notifica maintainer dentro de 2h; não espera sprint close |
| `-race` detectado | Upgrade automático para Critical; bloqueia release |
| CRLF / response splitting encontrado em agente X | Escalar para `http-protocol-security-auditor` para expansão |
| Timing leak p-value < 0.01 em auth | Escalar para `middleware-security-reviewer` + maintainer |
| Path bypass encontrado em agente X | Escalar para `path-routing-fuzzer` para differential confirmation |
| Zero-day composto (finding A + B implica vuln C) | Threat-modeler cria `TM-NNN` em findings.md + nova hipótese `H-NNN` em hypotheses.md |

### Cross-agent coordination
- `path-routing-fuzzer` + `http-protocol-security-auditor` — path/CRLF interaction
- `concurrency-security-auditor` + `middleware-security-reviewer` — race em middleware
- `timing-and-sidechannel-analyst` + `middleware-security-reviewer` — auth timing
- `fuzzing-and-property-engineer` + `path-routing-fuzzer` — share corpora em `/reports/path-routing-fuzzer/corpora/`
- `dos-resilience-tester` + `concurrency-security-auditor` — goroutine leak + pool interaction
- `go-sast-and-memory-auditor` é um **filtro paralelo** — corre sempre e informa todos os outros sobre red flags estáticos

### Threat-modeler consolidation passes
- Pass 1 (immediate após cada report): copia findings para `findings.md`
- Pass 2 (após todos reports): cross-reference findings → procura compostos
- Pass 3 (final): publica `posture.md` com recomendação
