## 7. Escalation paths (mandatory)

### Intra-sprint escalation
| Event | Immediate action |
|---|---|
| Any Critical finding | Threat-modeler notifies maintainer within 2h; does not wait for sprint close |
| `-race` detected | Automatic upgrade to Critical; blocks release |
| CRLF / response splitting found in agent X | Escalate to `http-protocol-security-auditor` for expansion |
| Timing leak p-value < 0.01 in auth | Escalate to `middleware-security-reviewer` + maintainer |
| Path bypass found in agent X | Escalate to `path-routing-fuzzer` for differential confirmation |
| Composite zero-day (finding A + B implies vuln C) | Threat-modeler creates `TM-NNN` in findings.md + new hypothesis `H-NNN` in hypotheses.md |

### Cross-agent coordination
- `path-routing-fuzzer` + `http-protocol-security-auditor` — path/CRLF interaction
- `concurrency-security-auditor` + `middleware-security-reviewer` — race in middleware
- `timing-and-sidechannel-analyst` + `middleware-security-reviewer` — auth timing
- `fuzzing-and-property-engineer` + `path-routing-fuzzer` — share corpora in `/reports/path-routing-fuzzer/corpora/`
- `dos-resilience-tester` + `concurrency-security-auditor` — goroutine leak + pool interaction
- `go-sast-and-memory-auditor` is a **parallel filter** — runs always and informs all others about static red flags

### Threat-modeler consolidation passes
- Pass 1 (immediate after each report): copies findings to `findings.md`
- Pass 2 (after all reports): cross-reference findings → search for composites
- Pass 3 (final): publishes `posture.md` with recommendation

- HTTP/1.1 framing in `net/http` parser (stdlib)
- HTTP/2 framing in `net/http2` (stdlib) — we cover via `govulncheck`
- TLS (stdlib) — outside scope (application-level)
- DNS / resolver — N/A

These risks are inherited from Go upgrade. The gate is `govulncheck ./...` green.
